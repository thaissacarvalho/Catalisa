# Requests for Comments

RFCs descrevem propostas antes da implementação. Elas existem para debate; não representam contrato disponível.

| RFC | Status | Tema |
| --- | --- | --- |
| [0001](./0001-participant-authentication.md) | Draft | Autenticação de participantes |
| [Template](./template.md) | — | Modelo para novas propostas |

## Ciclo

```text
Draft -> In Review -> Accepted -> Implemented
                  \-> Rejected
```

Quando uma RFC aceita resultar em decisão arquitetural duradoura, crie um ADR ao implementar.
